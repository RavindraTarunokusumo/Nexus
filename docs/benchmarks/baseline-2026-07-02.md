## Interpretation & top follow-ups

**What works.** Citation faithfulness is perfect (1.000) — every citation the model
emits traces back to a retrieved context block, so the evidence-chain plumbing (D1/D3)
is sound. Abstention is strong (category 1.000): the model reliably declines when the
corpus lacks the fact. The lifecycle worker (E1/E2) applied 13 supersessions via the
same-actor/same-type/newer-date facet heuristic with zero relations present.

**The dominant gap: no cross-document relations.** `classify_relations` only pairs
capsules **within a single document's** extraction run, so cross-doc edges — the exact
signal the superseded/authority_conflict/thesis questions probe — are never created.
Consequence chain:
- 0 relations → 0 theses (consolidation has nothing to cluster) → thesis category 0.417.
- supersession_correctness 0.000: answers don't surface the superseding fact because no
  `supersedes` relation links the newer capsule to the older one at retrieval time (the
  lifecycle heuristic marks the *older* capsule superseded, but D1's supersession
  aux-block needs the relation to find the pair).
- authority_conflict 0.167: no `contradicts` edge between the primary statement and the
  rumor, so the retrieval layer can't down-rank the low-authority capsule.

**Ranked next actions.**
1. Add a cross-document relation pass (batch capsules by object_family/actor across the
   whole domain, not just one doc) — highest leverage; unblocks thesis + supersession +
   authority_conflict simultaneously.
2. Feed lifecycle `superseded` state into a synthetic `supersedes` relation (or teach D1's
   supersession aux-block to also key off the facet heuristic) so retrieval surfaces the
   current fact even without an LLM-classified edge.
3. Raise T2 relation-budget headroom; verify `qwen3.6-flash` relation classifications
   aren't all returning "none" once cross-doc pairs exist.
4. Reduce forbidden_violation (0.091) — mostly in superseded/authority categories where the
   stale/rumored value leaks in; ties back to actions 1–2.

Correctness (0.568) and evidence recall (0.398) are a credible first pass for a
zero-tuning run; the ceiling is gated by relations, not by the retrieval/answer path.
