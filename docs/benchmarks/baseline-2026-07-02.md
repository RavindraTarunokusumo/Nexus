## Bring-up bugs found and fixed (this is why an earlier draft of this file reported
0 relations / 0 theses)

1. **`capsule_segments.role` CHECK violation** — `build_capsule_row` wrote an invalid
   `"support"` role, so every capsule write failed on a real DB; the first run produced
   zero capsules. Fixed: `"grounds"` default + claim_evidence→segment vocab translation.
2. **Supersession heuristic over-fired on historical events** — a newer same-actor/same-type
   record marked older *events* (GA dates, releases, funding) `superseded`, and retrieval
   only serves `active/confirmed/qualified`, so correct historical facts were filtered out.
   Fixed: heuristic restricted to `core_type="state_change"` (pricing/availability/api).
   Effect: `forbidden_violation` 0.091 → 0.000; `superseded` category 0.444 → 0.556.
3. **Relation classifier pointed at a dead model** — the pack's top-level `models.t2/t3`
   hardcoded `deepseek/deepseek-v4-flash`, which `_resolve_t2_model` returns; on DashScope
   that 404s, so relation classification silently failed and produced **0 relations → 0
   theses**. This — not a cross-document-architecture limit — was the real cause. Fixed:
   pack + config defaults switched to `qwen3.6-flash` / `qwen3.7-max`. Effect: 22 relations,
   7 confirmed-lifecycle capsules, 7 theses now populate.

## Interpretation & top follow-ups

**What works.** Citation faithfulness is perfect (1.000) — every emitted citation traces
to a retrieved block. Abstention is strong (1.000): the model declines cleanly on
out-of-corpus facts. With relations live, consolidation now produces theses and the
`confirmed` lifecycle state (≥2 supporting relations) engages. The authority-conflict path
surfaces both a primary statement and a low-authority rumor with their epistemic weights.

**Remaining gaps (ranked).**
1. **Timeline (0.333) / temporal (0.250)** — the weakest area. Retrieval + answer phrasing
   miss some single-fact date lookups (e.g. a GA date) even though the capsule is now active.
   Likely an embedding-recall / prompt issue, not lifecycle. Investigate retrieval for
   short factoid queries.
2. **No explicit `supersedes` relations** — relations are `supports`/`other`; the classifier
   isn't emitting `supersedes`, so supersession still leans on the lifecycle facet heuristic.
   A cross-document relation pass keyed on same-actor state changes would raise
   supersession_correctness beyond 0.333.
3. **Run-to-run variance** — answer/extraction are non-deterministic (LLM); metrics move
   ±0.05–0.15 between runs. Report medians over ≥3 runs before treating a delta as signal.

Correctness (0.568), evidence recall (0.407), and faithfulness (1.000) are a credible
zero-tuning first pass; the living-knowledge stack (relations → theses → lifecycle) now
runs end-to-end on Qwen.
