## Summary

Implemented the Qwen memory query router (hackathon item H5): the existing
intent-classification call (T2 Qwen) now also returns a question shape —
`factoid` / `multi_doc` / `current_state` / `conflict` / `general` — in the same
single LLM call, and each shape dispatches a `RetrievalStrategy` (hybrid-score
weight overrides merged over pack weights, fetch-pool multiplier, top_k delta)
plus an answer-prompt hint. `general` is identical to pre-router behavior and is
the fallback on `LLMError` or an off-list shape. Targeted at (and validated
against) the weakest baseline benchmark category, timeline/factoid recall.
