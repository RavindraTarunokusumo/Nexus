## What Was Built

A `nexus` console-script CLI for monitoring and operating the Nexus Lite system. Registered via `[project.scripts]` in `pyproject.toml` — available on PATH after `pip install -e .`.

### New module: `app/cli/`

| File | Purpose |
|---|---|
| `config.py` | `CLISettings` — reads same `.env` as server; `database_url` optional for HTTP-only commands |
| `db.py` | 5 async DB readers: `count_documents_by_status`, `list_sources`, `list_documents`, `get_document_with_spans`, `get_status_snapshot` |
| `http.py` | 4 HTTP wrappers: `ingest_url`, `ingest_text`, `ingest_rss`, `search_spans` |
| `render.py` | 5 rich+JSON formatters + `print_ingest_result` helper |
| `main.py` | typer App — 8 commands, `_run()` event-loop helper, `_run_http()` error wrapper, `_require_db_url()` guard |

### Commands shipped

| Command | Access | Description |
|---|---|---|
| `nexus status` | Direct DB | Pipeline counts, last ingest, stuck detection |
| `nexus sources` | Direct DB | List sources, filter enabled/disabled |
| `nexus documents` | Direct DB | List docs with status/source/since/limit filters |
| `nexus document <id>` | Direct DB | Full doc detail with span table |
| `nexus search "<query>"` | HTTP | Semantic search via POST /search/spans |
| `nexus ingest url <url>` | HTTP | Trigger URL ingest |
| `nexus ingest text --file` | HTTP | Trigger text ingest from file |
| `nexus ingest rss <id>` | HTTP | Trigger RSS feed ingest |

Universal flags on all commands: `--json`, `--api-url`, `--db-url`.

## Key Decisions

- **Hybrid access model** — reads bypass the API for offline-capable monitoring; ingest/search go through HTTP to stay consistent with the canonical API contract
- **`database_url` optional** — HTTP-only commands (`search`, `ingest`) no longer fail at startup when `DATABASE_URL` is missing from the environment
- **`_run()` dual-mode dispatcher** — uses a ThreadPoolExecutor worker when inside an existing event loop (pytest-asyncio); direct `asyncio.run()` in production. Avoids `nest_asyncio` patching.
- **`render_search_results` uses flat fields** — matches the real server `SpanSearchResult` shape (`document_title`, `document_status`) not a nested `metadata` dict
- **Pre-commit complexity gate at 10** — `[tool.ruff.lint.mccabe] max-complexity = 10`; tests excluded (seed/fixture helpers legitimately exceed this)
- **Fast tests in pre-commit, testcontainers in CI** — commits are fast; Docker-dependent tests run in CI only
